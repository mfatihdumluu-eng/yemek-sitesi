# Yemek Sitesi / GastroPazar

Bu proje GastroPazar UI'sini görsel olarak korur ve demo localStorage verilerini Neon PostgreSQL üzerinde kalıcı hale getirir.

## Vercel
- Static frontend: `index.html`
- API: `/api/state`
- DB env: `DATABASE_URL`

## Database
Tables: users, chefs, products, requests, offers, promotions, orders, order_items, reviews.
